# cv/

Only `resume_web.pdf` is published from this folder. It is the web copy of the CV:
no Bode Prize until it is announced, no dollar amounts, no citation counts, no pending
invention disclosures.

To refresh the site from the CV, place the CV project's files here (resume.tex, its
build.sh and anything they need) and run `./build.sh` from the repository root.
`.gitignore` keeps those files, and the full resume.pdf, out of the public repository.
